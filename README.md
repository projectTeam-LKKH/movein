# 📂 Repository A  
## 프로젝트 기획 및 구조 검토 기록 (Archive)

안녕하세요!  
이 저장소는 프로젝트를 시작하며 아이디어를 기획하고
기술적인 테스트와 구조 검토를 진행했던 기록 보관소입니다.

초기 기획 단계에서의 시도와 판단을 바탕으로
웹 페이지의 완성도와 UI/UX 구현에 집중한 최종 프로젝트를 완성할 수 있었습니다.

---

## 💡 어떤 고민을 했나요?

### 1. 기술 구조 검토 및 효율성 파악
초기에는 서버 중심의 구조를 설계하며 테스트를 진행했습니다.  
그 과정에서 다음과 같은 점을 확인했습니다.

- **데이터 관리의 효율성**  
  관련 데이터를 액셀에 입력하는 식의 수동으로 관리하는 방식보다
  프론트엔드 로직에서 더 유연하게 다룰 수 있는 방식이 필요하다고 판단했습니다.

- **UI 완성도에 대한 우선순위**  
  정해진 일정 내에서  
  정교한 레이아웃과 부드러운 인터랙션을 구현하는 것이  
  이번 프로젝트의 핵심 목표라고 판단했습니다.

이러한 이유로,  
화면의 시각적인 완성도와 사용자 경험(UX)을 세밀하게 다듬을 수 있는  
**프론트엔드 중심 구조로 전환을 결정했습니다.**

---

### 2. 전략적 방향 수정
개발 환경과 팀 구성 변화에 맞추어
제한된 시간 내에 최상의 시각적 결과물을 만들 수 있는 방향을  
팀원과 함께 논의했습니다.

그 결과  
기능의 가짓수를 늘리기보다  
**사용자가 실제로 마주하는 화면의 퀄리티와  
UI 인터랙션의 품질을 높이는 데 모든 역량을 집중하기로 했습니다.**

---

## 🛠 새롭게 도전한 방향

- **UI/UX 구현 역량 집중**  
  HTML / CSS / JavaScript 중심의 독립적인 구조로 재설계했으며
  메인 페이지뿐 아니라 다양한 서브 페이지를 증설해  
  퍼블리싱 완성도를 높였습니다.

- **데이터 활용 방식 최적화**  
  서버 DB 대신 JSON 데이터 모델을 직접 설계하여  
  데이터 로직이 안정적으로 동작하고  
  유지보수가 용이한 화면을 구현했습니다.

- **단기 집중 개발 실천**  
  구현할 화면과 핵심 기능을 명확히 정의하고 
  Git 브랜치 전략을 통해 약 5일간의 집중해
  UI 구현과 버그 수정을 완수했습니다.
